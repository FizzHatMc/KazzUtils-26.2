# KazzUtils

A Minecraft mod that adds various quality-of-life features.

## Release Types

KazzUtils is distributed in three release types. Choose the one that fits your needs:

- **Stable** (version `X.0.0`, marked as "Latest") — These releases are thoroughly tested and stable. They are recommended for most players, but may not include the newest features.

- **Alpha** (version `X.X.0`, marked as "Pre-Release") — These releases include the latest features and changes, but may be unstable. Download these if you want to try out new functionality and don't mind occasional bugs.

- **Dev** (version `X.X.X`, marked as "Pre-Release") — These are very unstable builds intended for testing specific bug fixes. Only download a dev version if you were directed to do so by a developer or in an issue report.
